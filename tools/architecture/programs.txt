# The programs that `behavior.sh capture` runs, one line each. A line is
#
#   id | target | arguments | cuts
#
# id         the name of the file in the capture. `@layout` stands for each name
#            that `check_layout --list` prints at capture time (so a new layout
#            is captured without editing this file), `@plan` for each committed
#            plan, plans/<name>.json. A line that uses one gives a file for each.
# target     the Bazel target, run as `bazel run` would with the arguments that
#            BUILD.bazel gives it (the model's path), then these arguments.
# arguments  `-` for none, else split like a shell would; fixed, so that the output is the same on
#            every run. The seeds are explicit or the scene is --nominal.
# cuts       what is replaced by <wall> before the output is written, because it
#            is a wall-clock time (or computed from one), separated by ` ;; `, or
#            `-` for none. col:NAME is a column of a CSV table, tab:NAME[#K] a
#            column of an aligned table (--pretty), re:PATTERN the groups of a
#            regular expression in a line, digest replaces an output too large to
#            keep by its size and SHA-256. The full explanation is in
#            behavior_lib.py. Each cut is only a time: docs/architecture/behavior.md
#            (and notes) give the source line that shows it.
#
# Not here, and why (the longer account is docs/architecture/behavior.md):
#   viewer, viewer_arm, viewer_bay, viewer_cell, viewer_container,
#   viewer_conveyor, viewer_layout, viewer_pallet, viewer_suction, view_cell
#     open a window and need a display.
#   run_cell --planner ompl, print_plan --planner ompl
#     OMPL's planners are seeded from the clock: two runs differ.
#   print_rrt --sweep, --shorten-sweep, --nn
#     minutes of timing tables; --stats stands in for them.
#   run_gate with its default 8 trials of 30 modules
#     minutes; //:gate_test (tag gate, in `capture --gate`) runs the same.
#
